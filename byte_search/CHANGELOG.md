## 0.1.0

- Initial release.
  - `BytePattern`: Horspool-based byte matcher optimized for high-reject workloads
  - `ByteSet`: compiled byte membership table for constant-time classification
  - Utilities:
    - `indexOfByte`
    - `indexOfAnyByte`
    - `indexOfByteNotIn`
    - `startsWithBytes`
    - `endsWithBytes`
